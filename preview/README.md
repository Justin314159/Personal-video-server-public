# Home Video Library – static preview

Open `index.html` in a browser (double-click works; no server needed).
For the phone-sized view, use your browser's device toolbar at 390px width.

Everything runs against an in-browser mock of the server API with fake YouTube data.
Clicks are saved in localStorage; Settings → "Reset demo data" starts over.

Generated by `python scripts/build_preview.py` from `backend/homelib/static/` – don't edit by hand.
